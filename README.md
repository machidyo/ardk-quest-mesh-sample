# ardk-quest-mesh-sample
[ARDKをMeta Quest3で使う方法](https://qiita.com/matchyy/items/7e633838b7988d4a2955)で実装したサンプルプロジェクトです。
ARDKでMeshingできるところまで構築されています。
API Keyは含まれていませんので、上記URLを参考に取得してください。

# 環境
* Unity 6000.0.58f2
* [ARDK (Niantic Light Ship AR Plugin)](https://github.com/niantic-lightship/ardk-upm) v3.17.0
* [ARDK Quest3 (Naintic Lightship Meta Plugin)](https://github.com/niantic-lightship/ardk-quest3-upm) v3.17.0
* [Meta SDK](https://assetstore.unity.com/packages/tools/integration/meta-xr-all-in-one-sdk-269657) v81.0.0

# 使い方
[ARDKをMeta Quest3で使う方法](https://qiita.com/matchyy/items/7e633838b7988d4a2955)を見てください。
